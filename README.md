# Python QR Code Generator (Desktop App)

A Python 3.12 desktop application to generate QR codes with optional center logo and PNG export.

## Features
- URL or text to QR
- Center logo embedding
- High error correction
- Clean margins
- PNG export
- Desktop GUI (Tkinter)
- Python 3.12 compatible

## Tech Stack
- Python 3.12
- Tkinter
- qrcode
- Pillow

## How to Run
```bash
pip install -r requirements.txt
python app.py
